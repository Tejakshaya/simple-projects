# simple-projects

**Syncth player: A simple HTML file syncth player with vanilla HTML, CSS and the Web Audio API**

How to run:
- Download or save `index.html`
- Double click the file to open it. 

How to play:
- Click on the on-screen keys with your mouse or play using your keyboard.
